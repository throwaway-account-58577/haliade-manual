To install HaliadeOS, you must partition your drives first.

Preferably, you can partition your drive using the "cfdisk" utility

Before that however, do the "lsblk" command.
This shows you all the drives on your machine, and their partition
Identify the drive you want to install Haliade to, and then proceed with the partitioning.

Here is an example :

[-root | haliade-] ~ $ lsblk
NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
loop0    7:0    0  1.2G  1 loop
sda      8:0    0 16.1G  0 disk
sr0     11:0    1  1.3G  0 rom

where "sda" is the disk we want to install Haliade on.

Using cfdisk , we will create 2 partitions.

a boot partition, of Preferably 1 or 2 gigs
and a root partition, that will cover the whole drive.

do the command "cfdisk /dev/[your-drive]", this will bring you into a TUI for partitioning your OS.
create 2 new partitions :

/dev/[your-drive]1 : the boot partition, this is where your bootloader and kernel will live.
/dev/[your-drive]2 : the root partition, this is your entire system.

After you are done, verify with lsblk :

[-root | haliade-] ~ $ lsblk
NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
loop0    7:0    0  1.2G  1 loop
sda      8:0    0 16.1G  0 disk
|-sda1   8:1    0   15G  0 part
`-sda2   8:2    0  1.1G  0 part
sr0     11:0    1  1.3G  0 rom

As you can, see we have properly partitioned our drive, and we can now proceed to the installation.
to install Haliade, we will call the "zstrappa" command.
(please make sure you have partitioned the OS correctly, as all data from this disk will be wiped!)

This will convert your root drive to BTRFS
and your boot drive to FAT32

Usage: zstrappa [options] <root-device> [boot-device]

Options:
  --uefi        Force UEFI bootloader installation
  --bios        Force BIOS/legacy bootloader installation

Install Haliade OS from the live ISO to a target block device.

Arguments:
  root-device   Target root partition (e.g. /dev/sda2, /dev/nvme0n1p2)
  boot-device   Optional separate boot partition (e.g. /dev/sda1)

Examples:
  zstrappa /dev/sda2 /dev/sda1
  zstrappa --uefi /dev/sda2 /dev/sda1

in my case, this will be "zstrappa /dev/sda1 /dev/sda2"
after doing this commmand, zstrappa will copy a bunch of files over to your partitions, do not be alarmed, this is just how zstrappa does it.
zstrappa copies all the files and directories of the root tree of this live environment, allowing an offline and faster install.
zstrappa will also create a generation, we'll get to them later
after zstrappa is done installing, you can reboot the machine and use Haliade OS normally.
(If you are installing, go back to the manual after reboot so it can explain how to properly use it)
